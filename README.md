# 🎲 Dice Wars

A two-player dice game built with HTML, CSS and JavaScript.

[**▶️ PLAY DICE WARS**](https://calinbaciu93-design.github.io/dice-wars/)

## 🎮 About the Game

Dice Wars is a turn-based game for two players. The objective is to be the first player to reach **50 points** by rolling a dice and deciding when to bank your points.

But be careful! Roll a 1 and you lose all the points accumulated during your current turn.

## 📖 How to Play

1. **Roll Dice:** Click the Roll Dice button to generate a random number between 1 and 6.
2. **Keep Rolling:** If you roll anything other than a 1, the number is added to your current turn score.
3. **Hold:** Click Hold to add your current turn score to your total score. Your turn then passes to the other player.
4. **Watch Out for 1:** If you roll a 1, you lose all the points accumulated during that turn and your opponent takes over.
5. **Win the Game:** The first player to reach 50 points wins!

You can start a fresh game at any time using the New Game button.

## 🛠️ Built With

- **HTML5** – Game structure and layout.
- **CSS3** – Styling, layout and visual effects.
- **JavaScript (Vanilla)** – Game logic, dice rolls, score tracking and player switching.
